# trycool — Split PDF

One tool: split a PDF into separate files. Runs fully in the browser; no file upload.

## Run locally (Termux)
    npm install
    bash ~/dev-one.sh cool
Open http://localhost:4321/

## Build
    npm run build

## Before going live
- Domain used in code: trycool.app. Register it at your registrar before pointing it at the site.
