# trycool — Split PDF

One tool: split a PDF into separate files. Runs fully in the browser; no file upload.

## Run locally (Termux)
    npm install
    bash ~/dev-one.sh cool
Open http://localhost:4321/

## Build
    npm run build

## Before going live
- Change `site` in `astro.config.mjs` to the final domain (currently a placeholder).
- Note: trycool.com is already used by another company's website, so pick a different domain.
